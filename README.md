# 🤖 Discord Admin Bot (Game Management System)

بوت ديسكورد احترافي لإدارة اللاعبين والأنظمة داخل اللعبة  
مصمم بأسلوب **Modular + Secure + Production Ready**.

---

## 🚀 Features

### 🔐 Administration
- Ban / Unban players
- Check hold status
- Full admin action logging
- Rank management (Owner / Admin / Guard)

### 👤 Account Management
- Check account info
- Change password
- Generate new password
- Change player nickname

### 💰 Economy
- GP system (check / add)
- ZP system (check / add)
- Billing database support

### 📋 Logs & Monitoring
- Admin actions logged to a Discord channel
- Rank-based permissions
- Secure error handling

### 🧠 Smart Help System
- `/help` interactive menu (Select Menu)
- Commands shown based on user rank
- Prefix (`!`) + Slash (`/`) support
